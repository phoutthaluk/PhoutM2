ການຕິດຕັ້ງ Flutter SDK

1.ໃນເຂົ້າໄປດາວໂຫລດ Flutter SDK ຢູ່ໃນ Browser ແລ້ວພີມຄຳວ່າ Install Flutter

2.ຫລັງຈາກຫາເຫັນຕາມຮູບແລ້ວໃຫ້ ຈະເຫັນແຖບຂ້າງຊ້າຍກົດເຂົ້າໄປທີ່ Install manually.

3.ກົດແລ້ວ ສາມາດ ເລືອກຕາມ OS ຂອງອຸປະກອນ ຂອງທ່ານໄດ້ເລີຍ.ແລ້ວກົດດາວໂຫລດ ໃນຫົວຂໍ້ Install and set up Flutter. (ຂະຫນາດຈະຢູ່ປະມານ 2 GB)

4.ຫລັງຈາກໂຫລດແລ້ວ ຈະໄດ້ເປັນ ໄຟລ໌ .Zip ມາທຳການແຕກໄຟລ໌.

ແຕກໄຟລ໌

6.ຫລັງຈາກ ແຕກໄຟລ໌ແລ້ວ ໃຫ້ຍ້າຍ ຫຼື ສຳເນົາ ໄຟລ໌ ໄປໃວ້ໃນ Drive C. ແຕ່ກ່ອນອື່ນ ຕ້ອງສ້າງ ໂຟເດີ ຂຶ້ນມາໃຫມ່ກ່ອນ(ໃນການຕັ້ງຊື່ສາມາດຕັ້ງຕາມໃຈໄດ້ເລີຍ).ແລ້ວວາງໄຟລ໌ ທີ່ຍ້າຍ ຫຼື ສຳເນົາ ໃສ່ໃນ ໂຟເດີ.

ສ້າງ ໂຟເດີ. ຍ້າຍ ຫຼື ສຳເນົາ ໄຟລ໌

7.ຫລັງຈາກຍ້ານໄຟລ໌ແລ້ວ ໃຫ້ທຳການຫາ ໂຟເດີ ທີ່ຊື່ວ່າ "bin" ເພື່ອນຳໄປເຊັດ Part ເພື່ອທີ່ຈະສາມາດເອີ້ນໃຊ້ງານຕົວ Flutter ຜ່ານ Command

8.ໃຫ້ທຸກຄົນກົດເຂົ້າໃນ ໂຟເດີ bin ສຳເນົາ ທີ່ຢູ່ຂອງ ໂຟເດີ bin ຕາມຕຳແໜ່ງຮູບນີ້. ແລ້ວນຳໄປເຊັດ Part ໄດ້ເລີຍ.

9.ຫລັງຈາກນັ້ນ ໃຫ້ທຸກຄົນກົດປຸ່ມ Windows ແລ້ວພິມຄຳວ່າ env ຈະເຫັນ Program ຊື່ "Edit the system environment variables" ພາສາໄທ "แก้ไขตัวแปรสภาพแวดล้อมของระบบ" ກົດເປີດ.

10.ເມື່ອເປີດຂຶ້ນມາ ໃນກົດທີ່ Environment variables ຕາມຮູບເລີຍ.

10.1.ເມື່ອກົດເຂົ້າໄປແລ້ວ ຢູ່ໃນສ່ວນແລກ ຈະມີຄຳວ່າ Part ໃຫ້ ຄິກ2ເທີ່ອ(double kick)

10.2.ຈະມີຫນ້າ Edit ຂຶ້ນມາ ໃຫ້ເຕິມເຄື່ອງໝາຍ ; ຫລັງ WindowsApps ຕາມຮູບ ແລ້ວວາງທີ່ຢູ່ຂອງ bin ລົງໄປ ກົດ OK.

ແຕ່ໃນກໍລະນີ ທີ່ສອງ ທີ່ມີ Part ຫຼາຍອັນ ສາມາດ ກົດ New ແລ້ວເພີ່ມ ທີ່ຢູ່ໄດ້ເລີຍ.

11.ຫລັງຈາກເຊັດ Part ແລ້ວ ຂັ້ນຕອນຕໍ່ມາ ເລີ່ມຕົ້ນທົດສອບການໃຊ້ຄຳສັ່ງ Flutter. ສຳລັບ Windows ໃຫ້ເປີດ Command ຂື້ນມາ ກົດ Windows + R ພິມ (CMD) ກົດ Enter.ຫຼື ກົດ Windows ພິມ CMD ຈະມີ Program ຊື່ວ່າ Command Prompt ກົດ Enter.

ຫຼື ກົດ Windows ພິມ CMD ຈະມີ Program ຊື່ວ່າ Command Prompt ກົດ Enter.

11.1.ເມື່ອຫນ້າ CMD ຂື້ນມາແລ້ວຄຳສັ່ງທີ່ຈະໃຊ້ຄື “Flutter doctor“(ຖ້າບໍ່ເຊັດ Part ຈະບໍ່ສາມາດໃຊ້ຄຳສັ່ງນີ້ໄດ້).ເມື່ອຂຽນຄຳສັ່ງແລ້ວ ກົດ Enter ໄດ້ເລີຍ.ຈະມີລາຍລະອຽດ ວ່າມີສ່ວນໃດໃຊ້ງານ Flutter ໄດ້ແນ່.
