ການຕິດຕັ້ງ Visual Studio Code

1.ໃນເຂົ້າໄປດາວໂຫລດ Visual Studio Code ຢູ່ໃນ Browser ແລ້ວພີມຄຳວ່າ Visual Studio Code Download ໃຫ້ທຳການຕິດຕັ້ງ Visual Studio code

2.ເມື່ອຕິດຕັ້ງແລ້ວກົດໃຊ້ງານໄດ້ເລີຍ.

2.1.ຊັ້ນຕອນຕໍ່ໄປແມ່ນການຕັ້ງຄ່າ ຂອງ VS Code

2.2.ສ່ວນແລກແມ່ນ ແມ່ນສ່ວນຂອງ Terminal

2.3.ຊ້າຍເທິ່ງ ຈະມີຄຳວ່າ Terminal ກົດ ຈະມີໃຫ້ເລືອກ ກົດ New Terminal.

Terminal ເລີ່ມຕົ້ນຈະເປັນ PowerShell ໃຫ້ປ່ຽນເປັນ Command Prompt.

2.4.ເມື່ອກົດແລ້ວຈະມີຫນ້າຕ່າງທາງລຸ່ມຈໍຂື້ນມາ. ທາງຂວາຈໍ ຈະເຫັນຄຳວ່າ PowerShell ໃຫ້ກົດເຄື່ອງໝາຍ Drop-down (ຂ້າງໆ ເຄື່ອງໜາຍ "+")

ກົດທີ່ Select Default Profile

ເລືອກເປັນ Command Prompt

2.5 ທຳການລົບຫນ້າຕ່າງ Terminal (ທາງຂວາຈໍ ມີເຄື່ອງໜາຍ ຖັງຂີ້ເຫຍື່ອ ກົດ.) ແລ້ວກົດອອກຈາກ Program ເພາະເມື່ອຕິດຕັ້ງ VS Code ໃຫມ່ຈະຫາຄຳສັ່ງບໍ່ເຫັນໃຫ້ປິດ Program ເຂົ້າໃຫມ່

2.6 ເມື່ອເປີດ Program ຂື້ນມາໃຫມ່. ເປີດ Terminal ແລ້ວພີມຄຳສັ່ງ "Flutter doctor" ມັນຈະສະແດງລາຍລະອຽດທີ່ມີ Program ທີ່ພ້ອມໃຊ້ງານ Flutter ໄດ້.

ຂອງ Program ທີ່ໃຊ້ຈະເປັນ VS Code ຖ້າມີການຕິກ ✓ ແມ່ນພ້ອມໃຊ້ການແລ້ວ.

ການຕິດຕັ້ງ Extension ທີ່ຕ້ອງໃຊ້ໃນ Visual Studio Code

3. Extension ທີ່ຈະໃຊ້ໃນ Visual Studio Code ຫາ Icon ຕາມຮູບນີ້ ກົດເຂົ້າໄປ

Extension ທີ່ຈະຕິດຕັ້ງ

ຂັ້ນຕອນການສ້າງໂປຣເຈັກໃໝ່ ແລະ ການສັ່ງ Run Project.

4. ຂັ້ນຕອນການສ້າງໂປຣເຈັກໃຫມ່ຫາຄຳວ່າ View ຊ້າຍເທິ່ງ ແລ້ວເລືອກ ບັນທັດແລກ

4.1 ຈະມີຕົວເລືອກໃຫ້ເລືອກ ການສ້າງໂປຣເຈັກ ຈະເລືອກ Flutter: Create New Project

4.2 ເມື່ອກົດ Create ແລ້ວ ຈະມີຕົວເລືອກໃຫ້ຫຼາຍ ເລືອກ Application.

4.3 ມັນຈະໃຫ້ເລືອກເກັບໄວ້ໃສ ກ່ອນອື່ນສ້າງ ໂຟເດີ ຕັ້ງຊື່ ເຂົ້າໄປໃນໂຟເດີ ແລ້ວ Select ໄດ້ເລີຍ.(ສາມາດເກັບຢູ່ບອນໃດກໍໄດ້ໃນຄອມຕ້ອງຕັ້ງຊື່ ແລະ ຮູ້ວ່າຢູ່ບອນໃດຈະດີທີສຸດ).

ໃນຮູບ ຈະເກັບໄວ້ໃນ Drive C ສ້າງ ໂຟເດີ ຊື່: project

ເຂົ້າໄປໃນໂຟເດີ ແລ້ວ Select ໄດ້ເລີຍ

4.4 ເມື່ອກົດແລ້ວ ມັນຈະໃຫ້ຊຕັ້ງຊື່ Project ສາມາດຕັ້ງຊື່ໄດ້ຕາມສະດວກ ໃນການຕັ້ງຊື່ຈະບໍ່ສາມາດເວັ້ນວັກ ໄດ້ຕ້ອງ "_" ຂີດກ້ອງເທົ່ານັ້ນ. ກົດ Enter

4.5 ມື່ອກົດແລ້ວລໍຖ້າ ຈະມີ pop-up ຂຶ້ນມາ ກົດຕີກຖືກ ✓ ແລ້ວກົດ Yes ປຸ່ມຟ້າ.

ເມື່ອກົດແລ້ວລໍຖ້າ ໃຫ້ມັນໂຫລດ Project

4.6 ຫລັງຈາກນັ້ນໃຫ້ເລືອກ emulator ໃນການ Run Project

ຈະເຫັນວ່າ ມີຕົວເລືອກໃນການ Run ເຊັ່ນ: Chrome & Edge ແລະ Android emulator ອື່ນໆ.

4.7 ຫລັງຈາກເລືອກ emulator ສາມາດ Run ໂດຍການກົດທີ່ຄຳວ່າ Run ຊ້າຍເທິງ ເລືອກ Start Debugging ບັນທັດແລກ.
